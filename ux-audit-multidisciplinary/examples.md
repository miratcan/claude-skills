## Example: Directory App Homepage Audit

**Context**: Comprehensive UX audit of a Django-based directory site

### How to Run

1. Take screenshots of the page (desktop + mobile) or ask user to provide them
2. Read the HTML templates to understand DOM structure
3. Read the CSS files to understand styling
4. Apply the 9-section audit format from SKILL.md

### Key Findings Pattern

- First impression: Does the hero communicate value proposition in 5 seconds?
- Inline styles scattered across templates = maintenance nightmare + inconsistency
- Missing responsive breakpoints for key components
- Trust signals (reviews, badges) present but visually weak
- CTA buttons competing for attention without clear hierarchy

### Lesson

Always start with the user's perspective (screenshots), not the developer's perspective (code). The audit should feel like a design review, not a code review.
